# 🏨 LuxeStay – Hotel Booking Application

A premium hotel booking web application built with HTML, CSS, and JavaScript.

## Features
- Stunning dark-themed UI with gold accents
- Room browsing with detailed cards (Deluxe, Suite, Penthouse, Villa)
- Interactive booking form with price calculation
- Responsive design for all screen sizes
- Smooth animations and transitions

## Pages / Sections
- **Hero** – Landing section with statistics
- **Quick Search** – Fast destination & date search bar
- **Rooms** – Grid of available room types
- **Booking Form** – Complete reservation form with live price summary
- **About** – Hotel features and amenities
- **Footer** – Contact and links

## Tech Stack
- HTML5
- Vanilla CSS3 (Glassmorphism, Animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Outfit, Playfair Display)

## How to Run
Simply open `index.html` in your browser. No build step required.

## Branch Strategy
- `main` – Production-ready code
- `develop` – Integration branch
- `feature/review-system` – User reviews feature
